# Omega Importaciones · Mayoristas

Lista de precios por mayor protegida con contraseña.
Enlace: https://omegaimportaciones.github.io/Mayoristas/

- Este repo NO lleva datos. Lee `../Omega/data/products.json` y `../Omega/data/mayoristas.enc`
  del sitio principal (ver `js/config.js` → `DATOS`).
- Para actualizar precios: usa el Generador Omega y sube los archivos al repo **Omega**.
- La contraseña es la misma con la que el Generador cifró `mayoristas.enc`.
- `js/vault.js` es idéntico a `js/core/vault.js` del sitio principal y a `js/vault.js` del Generador.
